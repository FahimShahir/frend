## ✨ ফিচারস

| কমান্ড | কাজ |
|--------|-----|
| `মনে রাখ: [কথা]` | নোট সেভ করো |
| `মনে করিয়ে দে [কথা] [সময়]` | রিমাইন্ডার সেট করো |
| `কী মনে রাখলি?` | সব নোট দেখো |
| `খুঁজে দে [শব্দ]` | নোট সার্চ করো |
| `ভুলে যা [নম্বর]` | নোট মুছো |
| `আমার রিমাইন্ডার` | রিমাইন্ডার তালিকা |
| `রিমাইন্ডার বাতিল [নম্বর]` | রিমাইন্ডার বাতিল |

### 🧠 AI স্মার্ট রিমাইন্ডার _(নতুন!)_
যেকোনো কথা লিখলে AI নিজেই বুঝবে:
```
তুমি: কাল দেখা হবে
ফ্রেন্ড: 🧠 স্মার্ট সাজেস্ট: "কাল দেখা হবে" মনে রাখতে চাও?
তুমি: হ্যাঁ
ফ্রেন্ড: ⏰ রিমাইন্ডার সেট হয়েছে!
```

### 📅 Google Calendar Sync _(নতুন!)_
রিমাইন্ডার সেট করলেই Google Calendar-এ চলে যাবে।
```
node setup-calendar.js চালিয়ে একবার সেটআপ করো।
```

### 🎤 ভয়েস কমান্ড _(নতুন!)_
ভয়েস মেসেজ পাঠাও — AI শুনবে, বুঝবে, কাজ করবে!
```
🎤 ভয়েস: "কাল সকালে মিটিং আছে মনে করিয়ে দিও"
ফ্রেন্ড: শুনলাম: "কাল সকালে মিটিং আছে..."
         ⏰ রিমাইন্ডার সেট হয়েছে!
```

### 📍 লোকেশন রিমাইন্ডার _(নতুন!)_
নির্দিষ্ট জায়গায় পৌঁছালে রিমাইন্ডার:
```
লোকেশন রিমাইন্ডার: সুপারশপ → ডিম কিনতে হবে
```
_(সুপারশপে গিয়ে লোকেশন শেয়ার করলে ট্রিগার হবে)_

### 📴 অফলাইন মোড _(নতুন!)_
ইন্টারনেট বা WhatsApp বিচ্ছিন্ন থাকলেও কোনো রিমাইন্ডার মিস হবে না!
- **Windows Desktop Notification**: অফলাইনে থাকা অবস্থায় রিমাইন্ডার সরাসরি কম্পিউটারের স্ক্রিনে পপআপ ও সাউন্ড সহ আসবে।
- **স্বয়ংক্রিয় কিউ (Queue)**: পুনরায় WhatsApp সংযুক্ত হলে মিস হওয়া সমস্ত নোটিফিকেশন স্বয়ংক্রিয়ভাবে WhatsApp-এ চলে আসবে।

### 🎮 গ্যামিফিকেশন _(নতুন!)_
কাজ সম্পন্ন করলে পয়েন্ট (XP), লেভেল এবং ব্যাজ অর্জনের মাধ্যমে প্রোডাক্টিভিটি বৃদ্ধি:
| কমান্ড | কাজ |
|--------|-----|
| `শেষ [নম্বর]` বা `done 1` | কাজ সম্পন্ন চিহ্নিত করো (+15 XP ও স্ট্রিক বোনাস) |
| `পয়েন্ট` বা `প্রোফাইল` | লেভেল বার, মোট XP, এবং বর্তমান স্ট্রিক কার্ড দেখো |
| `ব্যাজ` | অর্জিত ও লকড ব্যাজ শোকেস (🌟 প্রথম পদক্ষেপ, 🔥 ৩ দিনের আগুন, 👑 প্রোডাক্টিভিটি কিং) |

### 📅 ক্যালেন্ডার ভিউ _(নতুন!)_
সব রিমাইন্ডারকে টেক্সট ও ইন্টারঅ্যাক্টিভ ক্যালেন্ডার আকারে দেখার সুবিধা:
| কমান্ড | কাজ |
|--------|-----|
| `সাপ্তাহিক ক্যালেন্ডার` | চলতি সপ্তাহের ৭ দিনের রুটিন ও রিমাইন্ডার |
| `মাসিক ক্যালেন্ডার` | চলতি মাসের ক্যালেন্ডার গ্রিড ও আসন্ন রিমাইন্ডার তালিকা |

### ⏰ স্মার্ট নোটিফিকেশন টাইমিং _(নতুন!)_
ব্যবহারকারীর অভ্যাস ও পূর্ববর্তী কাজের সময় বিশ্লেষণ করে বুদ্ধিমান রিমাইন্ডার সময় সাজেস্ট করে:
| কমান্ড | কাজ |
|--------|-----|
| `স্মার্ট সময়` বা `টাইমিং` | তোমার পিক প্রোডাক্টিভ আওয়ার্স ও টাইমিং প্রোফাইল |
| `মনে করিয়ে দে ওষুধ` | সময় উল্লেখ না করলে AI ক্যাটেগরি ও অভ্যাস অনুযায়ী সেরা সময় সাজেস্ট করে |

### 🔄 মাল্টি-ডিভাইস সিঙ্ক _(নতুন!)_
একই রিমাইন্ডার ফোন, ট্যাবলেট, কম্পিউটার—সব ডিভাইসে রিয়েল-টাইমে সিঙ্ক থাকে:
1. **WhatsApp মাল্টি-ডিভাইস**: ফোন, ট্যাবলেট এবং পিসির WhatsApp-এ একই সাথে রিমাইন্ডার আসে।
2. **Google Calendar ক্লাউড সিঙ্ক**: Android, iPhone, iPad ও Mac/Windows ক্যালেন্ডার অ্যাপে সিঙ্ক ও পুশ নোটিফিকেশন।
3. **লাইভ ওয়েব পোর্টাল**: যেকোনো ফোন/ট্যাবলেট/পিসির ব্রাউজারে `http://<IP>:3000` বা `http://localhost:3000` খুললে লাইভ ক্যালেন্ডার ও এক ক্লিকে টাস্ক সম্পূর্ণ করার সুবিধা।
- কমান্ড: `সিঙ্ক` বা `ওয়েব`

### 📊 অ্যানালিটিক্স ও ইনসাইটস _(নতুন!)_
ব্যবহারকারীর অভ্যাস ট্র্যাক করে বিশদ রিপোর্ট ও বুদ্ধিমান পরামর্শ প্রদান করে:
| কমান্ড | কাজ |
|--------|-----|
| `রিপোর্ট` বা `বিশ্লেষণ` | কোন সময়ে বেশি রিমাইন্ডার লাগে, কোন কাজ বেশি ভুলে যান ও ক্যাটেগরি হিসাব |
| `ইনসাইট` বা `পরামর্শ` | ব্যক্তিগত অভ্যাস ও প্রোডাক্টিভিটি বাড়ানোর AI টিপস |
| `স্ট্যাটস` বা `হিসাব` | তাৎক্ষণিক পরিসংখ্যান ও নোট/রিমাইন্ডার সংখ্যা |

### ☁️ ক্লাউড ব্যাকআপ (Google Drive ও OneDrive) _(নতুন!)_
সব রিমাইন্ডার, নোট, গ্যামিফিকেশন স্কোর ও ডেটাবেস নিরাপদে Google Drive ও OneDrive ক্লাউডে সেভ হয়ে থাকে:
1. **Microsoft OneDrive স্বয়ংক্রিয় ক্লাউড সিঙ্ক:** 
   - সিস্টেমে OneDrive থাকলে সরাসরি `%USERPROFILE%\OneDrive\FREND_Backups\` ফোল্ডারে ব্যাকআপ কপি হয়ে যায়।
   - উইন্ডোজের ব্যাকগ্রাউন্ড OneDrive সিঙ্ক সার্ভিসের মাধ্যমে এটি নিমেষেই Microsoft OneDrive ক্লাউডে জমা হয়।
2. **Google Drive ক্লাউড সিঙ্ক:**
   - Google Drive API-এর মাধ্যমে `FREND_Backups` ফোল্ডারে স্বয়ংক্রিয় ক্লাউড আপলোড।
   - পিসিতে Google Drive Desktop থাকলে লোকাল ড্রাইভেও অটো-সিঙ্ক হয়।
3. **১-ক্লিক ওয়েব ডাউনলোড:**
   - মোবাইল বা পিসির ব্রাউজার ড্যাশবোর্ড থেকে ১-ক্লিকে ডাউনলোড: `http://<IP>:3000/api/backup/download`
4. **স্বয়ংক্রিয় ব্যাকআপ:**
   - প্রতিদিন রাত ১২:০০ টায় (00:00) স্বয়ংক্রিয়ভাবে ক্লাউড ব্যাকআপ এক্সিকিউট হয়।

| কমান্ড | কাজ |
|--------|-----|
| `ব্যাকআপ` / `ড্রাইভ ব্যাকআপ` / `ওয়ানড্রাইভ` | তাৎক্ষণিক ক্লাউড ব্যাকআপ তৈরি ও Drive/OneDrive-এ সেভ |
| `রিস্টোর` / `restore` | সর্বশেষ ব্যাকআপ থেকে সমস্ত তথ্য ও রিমাইন্ডার নিরাপদে রিস্টোর |

## 🚀 কীভাবে চালাবো

### ১. `.env` ফাইল তৈরি করো
```bash
copy .env.example .env
```
`.env` ফাইলে Gemini API key দাও:
```
GEMINI_API_KEY=your_key_here
```
> 🆓 বিনামূল্যে পাবে: https://aistudio.google.com/

### ২. বট চালাও
```bash
npm start
```

### ৩. QR কোড স্ক্যান করো
WhatsApp → ⋮ → **Linked Devices** → **Link a Device** → QR স্ক্যান

### ৪. (ঐচ্ছিক) Google Calendar সেটআপ
```bash
node setup-calendar.js
```

### ৫. মাল্টি-ডিভাইস ওয়েব ড্যাশবোর্ড
যেকোনো ফোন, ট্যাবলেট বা পিসির ব্রাউজারে যাও:
```
http://localhost:3000
```

## 📁 প্রজেক্ট স্ট্রাকচার

```
frend/
├── index.js              # মেইন বট (AI, Calendar, Voice, Location, Offline, Gamify, Sync)
├── setup-calendar.js     # Google Calendar সেটআপ
├── src/
│   ├── handler.js        # সব কমান্ড + AI confirmation + Gamification
│   ├── database.js       # SQLite (notes, reminders, gamification)
│   ├── timeParser.js     # বাংলা সময় পার্সার
│   ├── aiAnalyzer.js     # Gemini AI (স্মার্ট রিমাইন্ডার + ভয়েস)
│   ├── calendarSync.js   # Google Calendar API
│   ├── calendarView.js   # সাপ্তাহিক ও মাসিক ক্যালেন্ডার ভিউ
│   ├── gamification.js   # XP, লেভেল, স্ট্রিক ও ব্যাজ সিস্টেম
│   ├── smartTiming.js    # ব্যবহারকারীর অভ্যাসভিত্তিক নোটিফিকেশন টাইমিং
│   ├── webDashboard.js   # মাল্টি-ডিভাইস লাইভ ওয়েব পোর্টাল ও সিঙ্ক
│   ├── locationReminder.js # লোকেশন-ভিত্তিক রিমাইন্ডার
│   ├── offlineNotifier.js  # অফলাইন ডেস্কটপ নোটিফিকেশন + কিউ
│   ├── cloudBackup.js      # Google Drive ও OneDrive ক্লাউড ব্যাকআপ
│   └── analytics.js      # অভ্যাস ট্র্যাকিং, পিক আওয়ার্স ও রিপোর্ট
├── data/                 # ডেটাবেস + session + backups (auto-created)
├── .env                  # API keys (নিজে তৈরি করো)
├── .env.example          # টেমপ্লেট
└── credentials.json      # Google OAuth (ঐচ্ছিক)
```
